VIX Volatility Regime Forecasting
View on GitHub → Read Report →

End-to-end ML classification project predicting next-day VIX volatility regimes (Low / Medium / High) from 9,110 trading days of CBOE data. Engineered nine leakage-free features from VIX close prices, applied a strict chronological train/validation/test split, and benchmarked five models — logistic regression, random forest, XGBoost, MLP, and a PyTorch deep network — against a persistence baseline. The core finding was a rigorous null result: VIX regime persistence is so structurally strong (lag-1 autocorrelation > 0.98) that no model achieves a statistically significant improvement over simply carrying forward today's regime (McNemar p = 0.85). The project demonstrates that the options-implied nature of VIX sets an informational ceiling that univariate features alone cannot overcome.

Python scikit-learn XGBoost PyTorch Time Series Statistical Testing Financial Analytics
Organisational Network Analysis
Read Report →

Case study analysis of a fictional 28-employee London consultancy (IdeaWeb). Computed degree, closeness, betweenness, and eigenvector centrality across a formal collaboration network — identifying the group head as the critical bottleneck (betweenness = 0.467) despite having fewer direct connections than team leads. Proposed an evidence-based floor allocation minimising severed formal ties. Then diagnosed why client satisfaction declined post-move by analysing a parallel informal lunch network: the formal-network-based split had severed key informal ties driving creative performance. Applied community detection to propose a revised split preserving those connections. Finally, interpreted a multivariate OLS regression on 438 employees across 16 global offices — finding formal betweenness the strongest predictor of promotion (+11.3pp per SD), informal degree the strongest protective factor against negative reviews, and a 12pp female promotion deficit that exceeded every network coefficient in magnitude.

R Network Analysis Centrality Metrics Community Detection OLS Regression Data Visualisation
Causal Inference, Pricing & Targeting in E-Commerce
Part I: Pricing & Causal Inference → Part II: Segmentation & Targeting →

Two-part quantitative project on causal reasoning and predictive targeting using real e-commerce sales data. Part I built a marketing mix model, diagnosed endogeneity in price estimation, and applied Instrumental Variables to recover a clean causal price effect — correcting the bias in a naive OLS estimate. Also designed an A/B/N experiment and proposed a Regression Discontinuity Design to isolate the causal impact of star ratings on sales. Part II applied RFM segmentation, K-means clustering, and supervised learning models (decision tree, random forest) to identify high-value customer segments and optimise targeting ROI — improving campaign return from −22% (blanket) to +40% (targeted).

R Causal Inference Instrumental Variables RFM Segmentation Machine Learning A/B Testing
Sustainability Analytics & OPEX Regression
Read Report → View Excel →

Case study statistical analysis of 200 European firms across Construction, Manufacturing, and Transportation to understand OPEX drivers and evaluate whether sustainability initiatives aligned with environmental performance. Applied chi-square tests and Welch t-tests to assess whether green programme participation correlated with recycling outcomes — finding no statistically significant association before controlling for firm size. Built a log-log OLS regression (R² = 0.89) with employment, CAPEX, and sustainability investment elasticities, sector fixed effects, and full diagnostics: Shapiro-Wilk, Breusch-Pagan, VIF, Cook's distance, and HC1 robust standard errors as a robustness check. Key finding: sustainability investment reduces OPEX with elasticity −0.47 (p < 0.001); programme participation has no significant conditional effect — diagnosing a design gap rather than a data gap.

R OLS Regression Hypothesis Testing Diagnostic Testing Robust Standard Errors Sector Fixed Effects
